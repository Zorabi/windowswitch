# 宣传素材

| 文件 | 尺寸 | 用途 |
| --- | --- | --- |
| `hero.png` | 3600 × 2000 | README 主图，展示窗口列表与默认快捷键 |
| `social-card.png` | 3200 × 1800 | 横版宣传图，突出窗口切换与固定搜索 |

主图为界面示意，使用示例窗口名称，不包含用户窗口或截图。素材使用项目图标、系统字体和 SF Symbols。

编辑 `scripts/render-marketing.swift` 后，在项目目录运行以下命令重新生成：

```bash
swift scripts/render-marketing.swift
```

项目原创图形与排版采用 AGPL-3.0-only；系统字体及 SF Symbols 的权利属于其各自权利人。
