# 窗序

[![Swift / AppKit](https://img.shields.io/badge/Swift-AppKit-5268CA)](#开发)

窗序是一款 macOS 窗口切换工具，用于搜索、选择并聚焦具体窗口。

![窗序：窗口切换、键入搜索与默认快捷键](Assets/marketing/hero.png)

*图中为界面示意，使用示例窗口名称。*

## 功能

- **按窗口切换**：显示应用图标、窗口标题与最小化状态，按最近使用顺序排列。
- **关闭后返回**：`Command+W` 关闭最后一个可见窗口后，尝试返回最近使用的其他可见窗口；原应用仍可通过重开入口参与切换。
- **提前准备列表**：后台预热与刷新，唤出时优先显示缓存；后台更新保留搜索内容与选中的窗口。首次启动、列表尚未准备好时可能短暂加载。
- **两种确认方式**：支持回车确认、松开修饰键即切换；搜索面板可保持打开。
- **独立搜索入口**：默认 `Option+Space` 打开固定搜索；切换过程中也可按 F 或空格进入搜索。
- **应用过滤**：按应用屏蔽重开入口或全部条目，Finder 默认仅屏蔽重开。
- **可选快捷键**：切换与搜索分别自定义，支持清除和恢复默认。
- **微信窗口处理**：分别列出可识别的主窗口、小程序及其他独立窗口；主窗口关闭后保留重开入口与最近使用顺序。
- **Dock 与菜单栏**：提供搜索、设置和暂停入口；已打开的窗序设置页也参与窗口切换。
- **本机统计**：查看今日与累计切换次数、自动返回成功与失败次数，以及平均、最近和最长处理耗时，支持清空。
- **原生外观**：支持浅色、深色及跟随系统，仅需辅助功能权限。

适合同时打开多个应用窗口、需要区分微信主窗口与小程序，或习惯通过键盘查找窗口的使用场景。

## 安装与快速开始

目前提供源码构建，尚未发布经 Apple 公证的预编译下载版本。安装 Xcode 与命令行工具后，在项目目录运行：

```bash
bash scripts/build.sh --install
```

1. 启动窗序，在「权限与隐私」中点击「前往授权」。
2. 在系统设置中为窗序开启辅助功能权限。
3. 按一次 `Option+Tab` 打开窗口列表，松开 Option。
4. 输入窗口或应用名称，用 Tab 或方向键选择，按回车切换。

默认采用回车确认。关闭设置窗口后，窗序继续运行；点击 Dock 图标可重新打开设置，Dock 右键菜单与菜单栏均提供搜索入口。

## 使用说明

### 快速切换与固定搜索

| 模式 | 操作 |
| --- | --- |
| 回车确认（默认） | 按一次切换快捷键，松开修饰键后继续选择或输入，回车确认 |
| 松开即切换 | 按住修饰键，连续按切换键选择，松开后切换；额外按 Shift 反向选择 |
| 固定搜索 | 按独立搜索快捷键；或在按住切换修饰键浏览时，按 F 或空格固定面板，再松开修饰键输入 |

列表按最近使用顺序排列；后台刷新保留本轮已有条目的相对顺序，重新唤出时更新排序。

在「通用 → 切换方式」中选择确认方式。**F 与空格作为固定搜索按键，仅用于仍按住切换修饰键的浏览阶段；进入搜索后，字母 `f` 是正常输入。**

例如将切换设为 `Command+Tab`：按住 Command 浏览时，再按 F 或空格即可固定搜索，无需额外再按一次 Command。该阶段的空格由窗序接收，不传给其他应用。面板关闭后，未分配给窗序的组合继续由系统或原应用处理。

### 默认快捷键

| 范围 | 按键 | 行为 |
| --- | --- | --- |
| 全局 | `Option+Tab` | 打开列表或选择下一项 |
| 全局 | `Option+Space` | 打开或聚焦固定搜索 |
| 面板 | `Tab` / `↓` | 下一项 |
| 面板 | `Shift+Tab` / `↑` | 上一项 |
| 面板 | `Return` | 切换到所选窗口 |
| 面板 | `Esc` / `Command+W` | 关闭面板 |
| 窗序前台 | `Command+F` | 打开固定搜索或聚焦搜索框 |
| 窗序前台 | `Command+,` | 打开设置 |
| 窗序前台 | `Command+1`～`6` | 按侧栏顺序切换设置页面，`Command+5` 使用统计，`Command+6` 关于 |
| 设置窗口 | `Command+M` | 最小化 |
| 窗序前台 | `Command+Q` | 退出 |

`Command+F` 不是全局快捷键，不会接管其他前台应用的搜索。

### 切换顺序与关闭窗口

窗序以窗口为单位记录最近使用顺序。唤出时将当前窗口放在首位，向前切换默认选择下一项，即上一次使用的窗口；当前应用被过滤时，直接选择首个可用条目。同一轮浏览期间，后台刷新不重新排列已有条目，关闭窗口对应的重开入口沿用其位置。下次唤出时再按最新使用记录排序。

按 `Command+W` 关闭前台应用的最后一个可见窗口后，窗序会尝试把焦点交还最近使用的其他可见窗口，称为**自动返回**。原应用若仍在运行且允许显示重开入口，就可以在下一次切换时重新打开。

例如 Zcode 和 Ghostty 都在运行且未被过滤：

| 操作 | 当前焦点 | 再次唤出时默认选择 |
| --- | --- | --- |
| 先使用 Zcode，再使用 Ghostty | Ghostty | Zcode |
| 用 `Command+W` 关闭 Ghostty 最后一个可见窗口，自动返回成功 | Zcode | Ghostty 的重开入口 |
| 确认切换到 Ghostty 的重开入口，窗口恢复成功 | Ghostty | Zcode |

自动返回只在窗序已授权、未暂停且存在可用目标时执行。关闭标签页、应用仍有其他可见窗口或显示关闭确认框时不触发；最小化、隐藏或被过滤的窗口不会作为自动返回目标。已打开的设置页也按最近使用顺序参与返回。不显示的内部窗口不会阻挡返回。如果你已经切到其他应用，窗序会取消这次交接。

窗序只观察 `Command+W`，不阻止应用处理关闭命令。点击关闭按钮或使用 `Command+Q` 时，窗序不会主动执行这项交接，系统及应用仍按自身行为处理。没有成功自动返回时，关闭窗口也不一定会改变前台应用，顶部菜单栏可能继续显示原应用名称。

### 自定义与窗口恢复

在「快捷键」中点击当前组合录制新快捷键；按 Esc 取消，点「清除」设为未设置，点「恢复默认」还原。切换与搜索组合不能冲突。清除切换快捷键后，原有系统组合不再被窗序接管；菜单栏与 Dock 入口仍可使用。

设置为 `Command+Tab` 时，将接管系统应用切换。独立搜索同样会接管分配给它的组合，避免与需要保留的其他应用快捷键重叠。

窗口条目尝试聚焦所选窗口，必要时恢复其最小化状态。没有可读取窗口的普通应用提供打开入口，其窗口恢复方式由目标应用决定。关闭最后一个窗口后，若应用仍在运行，唤出列表时会根据系统窗口信息补上打开入口，沿用原条目位置；应用过滤规则继续生效。「窗序 · 设置」关闭后会保留「重新打开」入口，也可以在「应用过滤」中选择只屏蔽重开或完全屏蔽。

### 微信窗口

- 主窗口、小程序与其他可识别窗口分别显示，按窗口 ID 区分；相同名称或尺寸不会导致合并。
- 没有标题的微信窗口显示为「微信 · 其他窗口 · 宽 × 高」，例如「微信 · 其他窗口 · 909 × 448」。
- 主窗口被 `Command+W` 关闭后，保留「重新打开主窗口」入口及原有最近使用顺序；如不需要，可在「应用过滤」中为微信选择「屏蔽重开」。
- 选择重开入口时，先请求微信在后台恢复，再识别并单独聚焦主窗口。找不到主窗口时不会回退为激活整个微信。

微信可能只向系统提供部分窗口信息，首次使用时可能需要分别点选相关窗口。当前使用环境已确认主窗口与小程序可来回切换，并保留最近使用顺序。

### 应用过滤

在「应用过滤」中为每个应用选择：

| 规则 | 效果 |
| --- | --- |
| 不屏蔽 | 窗口与重开入口正常参与切换 |
| 屏蔽重开 | 保留已有窗口，隐藏没有窗口时的打开入口 |
| 完全屏蔽 | 隐藏该应用的所有窗口与重开入口，搜索也不显示 |

Finder 默认「屏蔽重开」，可以随时改回「不屏蔽」。列表显示正在运行及已添加的应用；点击「添加应用…」可以为尚未运行的应用设置规则。规则自动保存在本机，只影响窗序，不改变 Dock 或其他应用的打开行为。

### 使用统计

在设置的「使用统计」中查看次数与耗时，也可在窗序前台按 `Command+5` 打开。

| 指标 | 统计含义 |
| --- | --- |
| 今日 / 累计切换 | 通过窗序主动选择外部窗口，且聚焦确认成功或应用打开请求成功的次数；取消和未确认不计入 |
| 自动返回成功 | `Command+W` 关闭最后一个可见窗口后，窗序自动交接到其他窗口且确认成功的次数；独立计数，不计入主动切换次数和耗时 |
| 自动返回失败 | 已选定目标并发起自动返回，但聚焦失败或未确认成功的次数；未触发、无可用目标或取消不计入 |
| 其中重开 | 从重开入口恢复应用且请求成功的次数，已包含在切换次数中 |
| 平均 / 最近 / 最长处理耗时 | 主动切换成功请求的处理耗时，不包含自动返回 |

手动点击其他应用、系统自行切换焦点、仅关闭窗口但未完成交接，都不会增加“自动返回”。

页面按“切换次数”和“处理耗时”集中展示，重开与自动返回次数放在次数组内。点击“统计说明”打开分组说明，按回车或点击“完成”关闭，也可按 Esc 返回；悬停指标可查看简要说明。

处理耗时从确认切换到收到结果，包含焦点校验；应用重开时以打开请求返回或主窗口聚焦确认完成为准，不代表画面绘制完成时间。统计从启用此功能的版本开始累计，不补录历史数据。今日次数按本机日期计算，清空统计不影响其他设置。

## 权限与隐私

窗序使用辅助功能权限读取窗口列表、处理切换快捷键并控制目标窗口。不请求屏幕录制权限，不截取屏幕，不上传窗口信息。

使用统计只保存本机汇总次数、日期和耗时，不保存应用使用明细、窗口标题或输入内容。

聚焦诊断仅在本机保存最近一次请求的进程与窗口编号、阶段耗时和结果，不包含窗口标题、搜索内容或聊天内容。实现及本机数据说明见 [开发文档](DEVELOPMENT.md)。

## 兼容性

| 项目 | 范围 |
| --- | --- |
| 最低构建目标 | macOS 13 |
| 当前使用环境 | macOS 27.0.1、Apple Silicon |
| 其他系统版本 | 尚未实测 |
| 微信主窗口与小程序 | 已在当前使用环境确认来回切换与最近使用排序；窗口识别取决于应用提供的辅助功能信息 |
| 桌面空间 | 跨桌面的窗口可能无法完整列出 |

聚焦使用部分私有或已弃用的系统接口，系统更新后仍需验证。目标应用可能只提供部分窗口信息，不能保证所有应用具有相同的窗口显示与聚焦行为。

## 开发

```bash

swift test

# 重新生成项目宣传图
swift scripts/render-marketing.swift
```

构建、签名、模块说明及已知限制见 [开发文档](DEVELOPMENT.md)。自动化测试不能替代真实窗口、输入法与桌面空间的人工验收。
